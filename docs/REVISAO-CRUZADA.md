# Revisão cruzada — pendente

Este é um roteiro, não um relatório de revisão já realizada.

## Execução (5 a 10 minutos)

1. Entregue o app a outro participante/grupo sem explicar os controles.
2. Peça para encontrar um título da lista, inclusive digitando sem acentos.
3. Peça para mostrar somente filmes com nota 7+ e ordenar por nota.
4. Peça para abrir um filme e voltar, observando se os filtros continuam ativos.
5. Peça para buscar um título inexistente e recuperar a lista completa.
6. Pergunte se ficou claro que a busca cobre apenas os filmes carregados.
7. Repita com internet indisponível e depois tente novamente com a conexão restaurada.
8. Teste também o app do outro grupo e registre o retorno que foi dado a eles.
